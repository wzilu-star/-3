## 怎么截

```cmd
cd /d <项目根目录>
.venv\Scripts\activate
streamlit run app/streamlit_app.py
```

浏览器打开 <http://localhost:8501>。**首次提问约 30 秒加载本地模型 + 60 秒生成**，
之后每题 20~60 秒，跨公司全景题约 4 分钟（上下文 36 块）。

## 建议截三张

| 建议命名 | 怎么操作 | 要看清什么 |
|---|---|---|
| `01_单公司问答.png` | 点侧边栏「贵州茅台2024年实现营业收入是多少？同比增速是多少？」 | 答案 + 展开的「引用来源」（`chunk_id`、页码、score） |
| `02_全景题_12家.png` | 点「2024年这12家白酒公司中，哪一家的毛利率最高？」 | 召回 36 块 / 覆盖 12 家；**侧边栏 `provider = local` 要入镜** |
| `03_检索过程.png` | 展开「检索过程」 | 向量 top-5 与 BM25 top-5 的对比 |

第 2 张最要紧：它对应结论页里那条核心发现——**全景题召回已覆盖 12/12 家却仍然答错，
瓶颈在模型的多源数值聚合，不在检索覆盖**。图文能互相印证。
