## 怎么重新截

```cmd
cd /d <项目根目录>
.venv\Scripts\activate
streamlit run app/streamlit_app.py
```

浏览器打开 <http://localhost:8501>。**首次提问约 30 秒加载本地模型 + 60 秒生成**，
之后每题 20~60 秒，跨公司全景题约 4 分钟（上下文 36 块）。

也可用 `python tools/shoot.py` 自动截（Playwright 驱动系统 Edge）。
