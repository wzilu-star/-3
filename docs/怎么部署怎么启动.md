## 第一步：装 Python（只做一次）

你机器上目前 `python`、`py`、`pip` 全部不存在（只有微软商店的占位程序）。
`git` 和 `node` 是有的。

### 装法

1. 打开 <https://www.python.org/downloads/>，下载 **Python 3.11** 或 **3.12** 的
   Windows installer (64-bit)。
   > 不建议用 3.13：部分包（faiss、pdfplumber 的依赖）在新版本上轮子还没跟上。
2. 运行安装程序，**务必勾选最底下那一行**：

   ```
   ☑ Add python.exe to PATH
   ```

   这一项不勾，后面所有命令都会报「不是内部或外部命令」，是新手最大的坑。
3. 选 `Install Now`，等它装完。

### 验证

**关掉所有已经开着的命令行窗口**（PATH 只在新建窗口生效），重新开一个 CMD 或 PowerShell：

```cmd
python --version
pip --version
```

两行都能打印版本号（如 `Python 3.12.8`）就算成功。

### 装不上的话

- 公司网络限制下载 → 换手机热点，或找 IT 要离线安装包；
- 提示 `Add to PATH` 忘了勾 → 重新运行安装程序选 `Modify` → `Add Python to environment variables`；
- 实在不想动环境 → **直接跳到「C. Colab」**，Colab 自带 Python，本机一行命令都不用敲。

## A · 本地零依赖启动（先看效果，5 分钟）

这条路的**唯一目的**是让你在下载任何 PDF、安装任何大依赖之前，
先把页面看到、把流程走通一遍。用的是脚本生成的**仿真数据**。

### 1. 建虚拟环境（强烈建议）

虚拟环境能把本项目的依赖和你机器其他项目隔离开，避免版本打架。

```cmd
cd /d F:\AI-study\work\baijiu-finrag

python -m venv .venv
.venv\Scripts\activate
```

成功后命令行开头会出现 `(.venv)`。
> 之后每次新开窗口，都要先 `cd` 再 `activate` 一次。

### 2. 只装最小依赖

A 路径**不需要** faiss、sentence-transformers，只需要 3 个轻量包：

```cmd
pip install pyyaml streamlit
```

`pyyaml` 读配置，`streamlit` 起页面。约 1 分钟。

### 3. 造仿真数据 + 建轻量索引 + 生成预览

```cmd
python tools/run_demo.py
```

它自动做三件事：造 12 家公司仿真语料 → 建轻量索引 → 渲染页面预览。
你会看到控制台打印 7 类问题的检索结果，最后提示：

```
检索结果 JSON → ...\demo\demo_results.json
页面预览 HTML → ...\docs\demo_preview.html
```

### 4. 打开页面

**方式一（最快）**：直接双击 `docs\demo_preview.html`。

这是一个静态快照，**不可交互**，但能让你看清页面结构和检索效果。

**方式二（真交互，推荐）**：

```cmd
streamlit run app/streamlit_app.py
```

浏览器会自动打开 `http://localhost:8501`。这时你可以：
- 在输入框随便提问；
- 左侧切换「混合 / 仅向量 / 仅 BM25」；
- 展开每条引用来源，看到原文片段和 `chunk_id`。

> 停掉服务：在命令行按 `Ctrl + C`。

### 5. 这一步你应该看到什么

- 页面上有 12 家公司、2024 年报；
- 问「贵州茅台2024年营业收入是多少」→ 召回贵州茅台的表格和文本块，带页码出处；
- 问「哪家毛利率最高」→ 走「跨公司配额召回」，召回 36 块覆盖全部 12 家。

**数字是编的**（脚本按行业量级模拟），但**流程、格式、出处全是真的**。

## B · 本地完整启动（真实年报）

从这里开始用真数据。**先确认 A 已经跑通**。

### 1. 装完整依赖

```cmd
cd /d F:\AI-study\work\baijiu-finrag
.venv\Scripts\activate

pip install -r requirements.txt
```

这一步会装 `faiss-cpu`、`sentence-transformers`、`pdfplumber` 等，**约 5–15 分钟**。

> 如果 `faiss-cpu` 装不上，可以先注释掉 `requirements.txt` 里那一行，
> 走「轻量后端」也能跑（见第 4 步的说明）。
> `sentence-transformers` 会连带装 PyTorch，体积较大（约 2GB），耐心等。

### 2. 下载年报

```cmd
python src/01_download.py
python src/01_download.py --check
```

约 200–400MB。`--check` 会列出哪几家没下到。

**下载失败怎么办**（很常见，不用慌）：
用浏览器手动下载，按这个路径放：
```
data\raw\贵州茅台_600519\2024_年报.pdf
data\raw\五粮液_000858\2024_年报.pdf
...
```
目录名 = `公司名_代码`，文件名固定为 `2024_年报.pdf`。放好后 `--check` 就绿了。

### 3. 抽取 → 切块

```cmd
python src/02_extract.py
python src/03_chunk.py
```

`02_extract.py` 跑完会打印一张自检表。**重点看「表格块」那一列：
任何一家是 0，都说明该 PDF 抽取异常**——通常是因为它是扫描件（没有文本层），
去巨潮换一份带文本层的版本。

### 4. 建索引（这一步最慢）

```cmd
python src/04_index.py
```

首次会下载 `bge-m3` 权重（**约 2GB**），然后编码，总共 **5–15 分钟**。

**不想等 / 显存不够**，先用轻量后端把页面跑起来：

```cmd
python src/04_index.py --backend light
```

> 两者的区别要说清楚：
> - `faiss` 后端 = 真·语义向量，问「营收」能匹配到「营业总收入」，**这是要交付的方案**；
> - `light` 后端 = TF-IDF + BM25 的纯词形匹配，**不做同义泛化**，只适合演示和联调。
>
> `config.yaml` 里 `index.backend: auto` 的含义是：
> 装了 faiss **且**建好了索引 → 用 faiss；否则自动降级 light 并打印提示。
> 所以你不会因为忘了建索引就撞上莫名其妙的报错。

### 5. 起页面

```cmd
streamlit run app/streamlit_app.py
```

打开 `http://localhost:8501`，这次是真数据了。

### 6. 跑评测

```cmd
python src/06_eval.py
```

会在 `eval/` 下生成 `results_*.md`，逐题列出召回块、答案、对错、错因。
**对错和错因需要你人工核对填写**（脚本给不出标准答案）。

## C · 上云：GitHub + Colab，拿到公网链接

这一步是为了**交付截图**和**给别人一个能点开的地址**。

### 先理清一个认知

> **Streamlit 是运行时服务，它没有可提交的静态页面。**
>
> 所以「把页面传到 GitHub」的正确含义是：
> **代码进仓库 → Colab 把服务跑起来 → 截图进仓库**。
> 你想要一个能点开的网址，靠的是 Colab 上的临时隧道链接，不是 GitHub。

### 1. 推代码到 GitHub

先在网页上建一个空仓库（**不要勾** Add a README，本地已有）：

```cmd
cd /d F:\AI-study\work\baijiu-finrag
.venv\Scripts\activate

git init
git add .
git commit -m "feat: 白酒行业财报 RAG 问答知识库"

git branch -M main
git remote add origin https://github.com/<你的用户名>/baijiu-finrag.git
git push -u origin main
```

**推送前自查**，确认 PDF、索引没被带上去：

```cmd
git ls-files | findstr /i "\.pdf"
git ls-files | findstr /i "\.pkl"
```

两条**都应该没有输出**。`.gitignore` 已经配好了。

> 如果你看到 `index/light_index.pkl` 被跟踪了，说明它是在建索引之后才被忽略规则覆盖的，
> 执行 `git rm --cached index/light_index.pkl` 再提交。

### 2. 在 Colab 打开 notebook

最省事的方式是改 URL 直接打开，免上传：

```
https://colab.research.google.com/github/<你的用户名>/baijiu-finrag/blob/main/notebooks/colab_deploy.ipynb
```

就是把 GitHub 文件地址里的 `github.com` 换成 `colab.research.google.com`。

然后：
- 第 1 格把 `REPO` 改成你自己的仓库地址；
- 菜单 `代码执行程序 → 更改运行时类型 → T4 GPU`（可选，CPU 也能跑）。

### 3. 按格往下跑

第 0 → 10 格顺序执行。耗时参考：

| 步骤 | 耗时 |
|---|---|
| 装依赖 | 1–3 min |
| 下载 12 份 PDF | 2–5 min |
| 抽取文字 + 表格 | 5–15 min |
| 建索引 | 5–15 min |
| 起服务 + 隧道 | 1 min |

### 4. 拿到页面地址

第 8 格跑 `cloudflared` 后，输出里会出现：

```
Your quick Tunnel has been created! Visit it at:
https://random-words-1234.trycloudflare.com
```

**这个网址就是你的问答页面**。浏览器打开 → 从侧边栏点一个示例问题 →
展开「引用来源」和「检索过程」→ 截图。

建议截 3 张：
1. 答案 + 引用来源（主图）
2. 「检索过程」展开（向量 top-5 / BM25 top-5）
3. 侧边栏切换检索模式后的对比（加分项）

### 5. 截图回本地提交

**在本地做，不要在 Colab 上 push**（还得配 token，没必要）：

```cmd
copy <截图文件> docs\screenshots\
git add docs/screenshots
git commit -m "docs: 补充问答页面截图"
git push
```

### 6. （可选）开一个静态展示页

仓库 → Settings → Pages → Source 选 `Deploy from a branch` →
Branch 选 `main`、目录选 `/docs` → Save。

几分钟后得到 `https://<你的用户名>.github.io/baijiu-finrag/`，
展示的是项目说明页（不是可交互问答，GitHub Pages 跑不了 Python）。

## 常见报错速查

| 报错 | 原因 | 解决 |
|---|---|---|
| `python 不是内部或外部命令` | 装 Python 时没勾 Add to PATH | 重装并勾选，或换新窗口 |
| `无法加载文件 ... 因为在此系统上禁止运行脚本` | PowerShell 执行策略 | 改用 CMD，或执行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| `ModuleNotFoundError: No module named 'yaml'` | 没装依赖 | `pip install pyyaml`，或确认虚拟环境已 activate |
| `ModuleNotFoundError: 'faiss'` | A 路径没装 faiss | 正常，会自动降级 light；要真语义检索就装 `faiss-cpu` |
| 下载 bge-m3 卡住 | 网络 | 它是从 HuggingFace 拉的；可先 `--backend light` 跳过 |
| 某公司「表格块 = 0」 | PDF 是扫描件 | 换带文本层的版本 |
| `localhost:8501` 打不开（Colab 里） | Colab 的端口不在你本机 | 必须用 cloudflared 隧道，`localhost` 只对 Colab 虚拟机有效 |
| cloudflared 链接第二天失效 | 临时隧道特性 | 正常；要固定地址得绑自有域名或换 Streamlit Cloud |
| Colab 断开后索引没了 | 运行时重置 | notebook 第 10 格备份到 Google Drive，下次 `cp` 回来 |
| Streamlit 页面改了代码没变 | 缓存 | 页面上按 `R` 重跑，或 `Ctrl+C` 重启服务 |
